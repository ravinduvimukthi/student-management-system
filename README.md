# Student Management System

A Java console application designed to manage student records and practise fundamental Data Structures and Algorithms (DSA).

## Project Overview

The Student Management System will allow users to register students, view student records, search by student ID, update details, delete records, and calculate average marks.

This project is developed as a learning project to improve Java programming, object-oriented programming, problem-solving, and algorithmic thinking.

## Technologies

- Java 24
- Apache Maven
- IntelliJ IDEA
- Git and GitHub

## Planned Features

- [ ] Add student records
- [ ] View all students
- [ ] Search students by ID
- [ ] Update student details
- [ ] Delete student records
- [ ] Sort students by marks using Bubble Sort
- [ ] Calculate average marks
- [ ] Validate user input
- [ ] Add unit tests

## Data Structures and Algorithms

- **ArrayList:** Store and manage student records.
- **Linear Search:** Find a student by ID.
- **Bubble Sort:** Arrange student records by marks.
- **Traversal:** Display records and calculate average marks.

## Requirements

- JDK 24
- IntelliJ IDEA with Maven support

## Running the Project

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow IntelliJ to import the Maven project.
4. Run the `Main` class after the application has been implemented.
